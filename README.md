# 3mf-viewer

CLI で起動し、指定したパス配下の 3MF / STL ファイルをブラウザで 3D プレビューするローカルビューア。
Go 製の単一バイナリで動作する (フロントエンドの three.js は `embed` でバイナリに埋め込み済みで、外部ネットワークは不要)。

## インストール

```sh
go install github.com/m-tkg/3mf-viewer@latest
```

ソースからビルドする場合:

```sh
git clone https://github.com/m-tkg/3mf-viewer.git
cd 3mf-viewer
go build -o 3mf-viewer .
```

Go 1.22 以降が必要。

## 使い方

```sh
3mf-viewer [path]
```

`[path]` にはディレクトリ (サブディレクトリも再帰的に探索) か、単一の `.3mf` / `.stl` ファイルを指定する。**省略するとカレントディレクトリ**を表示する。
起動するとローカル HTTP サーバが立ち、ブラウザが自動で開く。**CLI が動いている間だけ**閲覧できる (終了は Ctrl+C)。

```sh
3mf-viewer                                  # カレントディレクトリを一覧表示
3mf-viewer ~/Downloads/3dModels            # ディレクトリ配下を一覧表示
3mf-viewer ./part.3mf                       # 単一ファイル
3mf-viewer ~/models --port 8080 --no-open   # ポート指定・ブラウザを開かない
```

### オプション

| オプション | 既定値 | 説明 |
| --- | --- | --- |
| `--port N` | `3977` | 待ち受けポート。未指定でポートが使用中のときは空きポートに自動で切り替える。明示指定したポートが使用中ならエラー終了する |
| `--host ADDR` | `127.0.0.1` | 待ち受けアドレス。既定ではローカルからのみ接続できる |
| `--no-open` | off | 起動時にブラウザを自動で開かない |
| `--interval D` | `1s` | ファイル変更の監視間隔 |
| `--version` | | バージョンを表示して終了 |

フラグは `[path]` の前後どちらにも置ける。

## 機能

- 指定パス配下の `.3mf` / `.stl` (拡張子の大文字小文字は問わない) を一覧表示。隠しファイル / 隠しディレクトリ (`.` 始まり) は除外
- 一覧のサムネイル。ブラウザ側で three.js を使って描画し、`localStorage` にキャッシュする (ファイルのサイズ・更新時刻が変わると再生成)。16 MB を超えるファイルはサムネイルを省略する
- 3D プレビュー: 左ドラッグで回転、ホイールでズーム、右ドラッグでパン。グリッド / ワイヤー表示の切り替え、視点リセット
- 3MF に複数のモデル (build item) がある場合は、「全体」と各モデルを個別に切り替えて表示できる。`components` や変換行列、単位 (`unit`)、production 拡張の外部モデルファイル (`p:path`) にも対応する。Bambu Studio / OrcaSlicer のオブジェクト名 (`Metadata/model_settings.config`) も表示名に使う
- 一覧とプレビュー画面から、ファイル名と絶対パスをクリップボードにコピーできる
- 一覧の「改名」ボタン / プレビュー画面の「名前を変更」ボタンから、ファイル名を変更できる。変更できるのは同じフォルダ内の名前 (拡張子より前の部分) だけで、拡張子は固定、別フォルダへは移動できない。変更先に同名のファイルがあれば上書きせずエラーにする。ディレクトリ指定で起動した場合のみ有効 (単一ファイル指定では変更できない)
- 画面左上の「フォルダを開く」で、ブラウザのフォルダ選択から別のフォルダを読み込める (下記)。「起動時のフォルダに戻る」で元の表示に戻る
- ファイルの追加・変更・削除を監視 (ポーリング + Server-Sent Events) し、一覧とプレビューを自動で更新する
- Z 軸を上とした座標系で表示する (3D プリンタ用データの一般的な向き)

## ブラウザでフォルダを読み込む

「フォルダを開く」ボタンで、ブラウザのフォルダ選択 (`<input webkitdirectory>`) からマシン上の任意のフォルダを読み込み、今の一覧を置き換えて表示できる。サーバが読める範囲 (起動時に指定したパス配下) は広がらない。サーバ側でマシン上の任意のフォルダを開く機能は無い。

- 一覧 (サブフォルダ込み、隠しファイル除外)、プレビュー、3MF 内の複数モデルの個別表示、サムネイルはサーバ側のフォルダと同じように使える
- 解析は、選んだファイルの中身をローカルの 3mf-viewer に送り、既存の Go のパーサで行う (`POST /api/parse`)。結果だけを返し、ディスクには保存しない。ブラウザ内解析 (three.js のローダ) にしなかったのは、Bambu / OrcaSlicer のオブジェクト名・components・変換行列・単位などの扱いをサーバ側フォルダと完全に揃えるため
- ブラウザは絶対パスを渡さないため、コピーできるのはファイル名と「選んだフォルダからの相対パス」だけ。画面にも絶対パスとは書かない
- 名前の変更とファイル監視による自動反映は使えない (ボタンを無効化し、理由を表示)。更新したいときはもう一度フォルダを開く
- 大きなファイル: 送信はファイルをストリームで行い、ブラウザのメモリに全体は載せない。64 MB を超えると「時間がかかる」旨を表示し、サーバの上限 (512 MB) を超えるファイルは開かない。16 MB を超えるファイルのサムネイルは省略する。一覧は 5000 件で打ち切る
- サーバは同時に 2 件までしか解析しない (メモリ保護)

## セキュリティ

- 既定では `127.0.0.1` のみで待ち受ける。`--host 0.0.0.0` などを指定すると、同じネットワークの他のホストから指定パス配下のモデルが閲覧できるようになる (起動時に警告を表示する)
- 配信するのは指定パス配下の `.3mf` / `.stl` のみ。`..` を含むパス、隠しファイル、指定パスの外を指すシンボリックリンクは拒否する
- ループバックで待ち受けている間は `Host` ヘッダがループバックのものだけを受け付ける (DNS rebinding 対策)
- 読み取り API は GET のみ。`POST /api/rename` (改名) と `POST /api/parse` (ブラウザで選んだファイルの解析) は、次をすべて満たすときだけ受け付ける: `Sec-Fetch-Site` / `Origin` が同一オリジン (どちらも無いリクエストは拒否)、`Content-Type` が期待どおり (rename は `application/json`、parse は `application/octet-stream`)、起動ごとに生成するトークン (配信する `index.html` に埋め込み、`X-Viewer-Token` ヘッダで送る) の一致。他サイトからの CSRF や DNS rebinding では名前を変えられず、ファイルを送り付けて解析させることもできない。`/api/parse` は本文の上限 512 MB、同時 2 件までで、本文はメモリ上でのみ扱いディスクに保存しない。サーバ上のパスは参照しない
- 名前変更は、対象と変更先が指定パス配下にあること (シンボリックリンク解決後) を検証する。新しい名前は、空、`/` `\`、先頭の `.`、制御文字、長すぎる名前を拒否する。上書きは `link` + `unlink` で防ぎ、確認と変更の間に同名ファイルができても上書きしない (ハードリンク非対応の FS では通常の rename にフォールバックし、わずかな競合の窓が残る)
- CSP などのセキュリティヘッダを付与する

## 開発

```sh
go test ./...
go vet ./...
```

構成:

- `main.go`: CLI (フラグ解析、ポート選択、ブラウザ起動)
- `internal/scan`: ファイル探索、配信可能パスの検証、変更の差分検出
- `internal/model`: 3MF / STL パーサ (三角形メッシュへの変換)
- `internal/server`: HTTP API、SSE、埋め込み静的ファイル (`static/`)。フロントの純粋ロジック (`static/local.js`) のテストは `internal/server/jstest/` (node があれば `go test` から実行される。単体では `node --test internal/server/jstest/`)

HTTP API:

- `GET /api/files`: モデルファイル一覧
- `GET /api/model?path=<相対パス>`: パース済みモデル (頂点・インデックスは base64 の little endian バイナリ)
- `GET /api/events`: ファイル変更通知 (SSE)
- `POST /api/rename`: 同一フォルダ内での改名。JSON `{"path": "<相対パス>", "name": "<拡張子を除いた新しい名前>"}`。成功すると `{"path": "<新しい相対パス>"}`。上書きは 409、不正な名前は 400、配下外は 403
- `POST /api/parse?name=<ファイル名>`: ブラウザで選んだファイルの解析。本文はファイルの中身 (`Content-Type: application/octet-stream`)、拡張子 (`.3mf` / `.stl`) で種別を判定。`/api/model` と同じ形式を返す。上限超過は 413、解析失敗は 422
- `GET /api/info`: ルートパスとバージョン

### 同梱ライブラリ

`internal/server/static/lib/` に [three.js](https://threejs.org/) r170 (MIT, `LICENSE-three.txt`) を同梱している。
